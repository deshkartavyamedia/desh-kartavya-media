# desh-kartavya-media
देश कर्तव्य मीडिया — लोकतंत्र का सच्चा पहरेदार।। राष्ट्र हित में समर्पित, बेबाक, बेधड़क और निष्पक्ष पत्रकारिता का संकल्प। हमारा उद्देश्य जनहित के मुद्दों को प्रमुखता देना, जनता की आवाज़ को मंच प्रदान करना, शासन-प्रशासन की जवाबदेही सुनिश्चित करने में योगदान देना तथा संविधान, लोकतांत्रिक मूल्यों और जन अधिकारों के प्रति जागरूकता बढ़ाना है।
